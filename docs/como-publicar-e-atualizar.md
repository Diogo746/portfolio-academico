# Atualizações do portfólio

[Início](../README.md) · [Organização do portfólio](README.md) · [Padrões de organização](padroes-de-organizacao.md)

Vou atualizar este repositório ao longo das disciplinas e do Projeto Integrador. As alterações serão feitas pelo site do GitHub, com os arquivos mantidos nas pastas correspondentes.

## Novas atividades

Cada atividade terá uma pasta identificada pelo número e pelo assunto do trabalho. O README da atividade reunirá seus dados, o enunciado, o objetivo, o desenvolvimento e os links para os arquivos.

Os [modelos de atividade](../modelos/atividade.md) servirão como padrão para os novos registros. O título, a data e a situação acompanharão o trabalho cadastrado.

## Arquivos e índices

Os arquivos ficarão na pasta da atividade ou da entrega correspondente. Os links para os anexos serão organizados no README do item.

Os índices terão o identificador, o título e a situação de cada conteúdo. Eles serão atualizados junto com os novos registros.

## Materiais de estudo

Vou reunir minhas anotações, os resumos e as referências na área de materiais da disciplina. Cada item seguirá o [modelo de registro de material de estudo](../modelos/material-de-estudo.md), com a fonte e os conteúdos relacionados.

## Projeto Integrador

Os documentos do PI serão atualizados conforme o projeto avançar. As entregas seguirão o [modelo de registro de entrega](../modelos/entrega-do-pi.md) e ficarão relacionadas aos documentos utilizados em cada etapa.

Quando uma atividade contribuir para o PI, a relação ficará registrada nas duas áreas, com links e uma breve explicação.

## Revisão e histórico

Antes de cada atualização, vou revisar os nomes, as datas, as situações e os links. As mudanças ficarão acompanhadas de uma mensagem que identifique o conteúdo alterado.
