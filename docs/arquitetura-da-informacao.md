# Arquitetura da Informação aplicada ao portfólio

[Início](../README.md) · [Organização do portfólio](README.md) · [Padrões de organização](padroes-de-organizacao.md)

## Objetivo da organização

Organizei este repositório para reunir minhas atividades acadêmicas e facilitar a localização dos materiais. Separei os conteúdos por disciplina e deixei uma área própria para o Projeto Integrador.

## 1. Classificação

Os conteúdos foram separados conforme sua finalidade. As disciplinas ficaram em `unidades-curriculares`, o PI ficou em `projeto-integrador`, os registros sobre a organização ficaram em `docs` e os modelos ficaram em `modelos`.

Dentro de cada disciplina, separei atividades e materiais de estudo. No PI, a divisão foi feita entre documentação, entregas e código.

## 2. Taxonomia

Defini uma hierarquia para manter o mesmo padrão nas disciplinas. O caminho de uma atividade passa pela unidade curricular, pela disciplina, pela pasta de atividades e pela pasta do trabalho.

Um exemplo dessa estrutura é:

`unidades-curriculares/inteligencia-artificial/atividades/atividade-01-modelo/README.md`

Os nomes das pastas ficaram em letras minúsculas e com as palavras separadas por hífens. Nos títulos das páginas, mantive os nomes completos das disciplinas.

## 3. Metadados

Separei os campos que serão usados para descrever cada trabalho: identificador, título, disciplina, autor, instituição, período, data, tipo, situação e palavras-chave.

Esses campos estão no [registro de atividade de Inteligência Artificial](../unidades-curriculares/inteligencia-artificial/atividades/atividade-01-modelo/README.md#metadados). As informações acadêmicas já estão registradas. Os dados de cada trabalho serão acrescentados junto com sua entrega.

## 4. Navegação

O README principal ficou como a entrada do portfólio. Nele estão os links para as disciplinas, o PI e os registros sobre a organização do repositório.

Nas páginas internas, organizei links para os índices e para as páginas anteriores. Dessa forma, os conteúdos podem ser acessados pelas próprias páginas do portfólio.

## 5. Encontrabilidade

Escolhi nomes relacionados ao conteúdo, códigos para identificar as disciplinas e índices para reunir os trabalhos. As atividades terão o número e o tema no nome da pasta, e suas palavras-chave serão registradas nos metadados.

O título, o identificador e a situação de cada trabalho ficarão no índice da disciplina. Os links serão atualizados quando novas atividades forem acrescentadas.

## 6. Relações entre conteúdos

Relacionei as disciplinas aos documentos do PI por meio de links. O [quadro de relações do projeto](../projeto-integrador/README.md#relações-com-as-unidades-curriculares) apresenta as contribuições previstas, e cada disciplina possui os caminhos para os documentos relacionados.

Também relacionei [Requisitos](../projeto-integrador/documentacao/requisitos.md) e [Plano de verificação e validação](../projeto-integrador/documentacao/plano-de-verificacao-e-validacao.md). Os casos de teste terão o identificador do requisito correspondente.

As contribuições das atividades serão registradas conforme os trabalhos forem acrescentados. Os links ficarão nas atividades e nos documentos do PI, acompanhados de uma explicação da relação.
