# Modelos de registro

[Início](../README.md) · [Organização do portfólio](../docs/README.md) · [Padrões de organização](../docs/padroes-de-organizacao.md)

Separei estes modelos para manter o mesmo padrão nos registros do portfólio.

- [Atividade](atividade.md): estrutura dos trabalhos das disciplinas.
- [Material de estudo](material-de-estudo.md): estrutura das anotações, dos resumos e das referências.
- [Entrega do PI](entrega-do-pi.md): estrutura dos registros das etapas do projeto.

Os modelos serão usados nos novos conteúdos. Os dados e os links acompanharão cada atividade, material ou entrega registrada.
