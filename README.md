## Projeto Integrador

Os materiais do [Projeto Integrador](projeto-integrador/README.md) ficarão reunidos em uma área própria, dividida em documentação, entregas e código. O tema, os integrantes e as informações do projeto serão registrados nessa seção.

## Organização dos conteúdos

Separei as atividades por disciplina. Cada unidade curricular possui um índice de atividades e uma área para materiais de estudo. Os links foram organizados para permitir o acesso aos conteúdos e o retorno às páginas anteriores.

Cada trabalho terá seu título, identificador, disciplina, autor, período, data, situação e palavras-chave registrados no README correspondente.

Essa organização aplica os conceitos de classificação, taxonomia, metadados, navegação, encontrabilidade e relações entre conteúdos. Registrei essas escolhas em [Arquitetura da Informação](docs/arquitetura-da-informacao.md).

## Atualizações

Vou acrescentar as atividades e os materiais conforme o andamento das disciplinas. Os índices e os links serão atualizados junto com os arquivos.

Nesta versão inicial, deixei um modelo de atividade em cada disciplina e um modelo de entrega do PI. Os campos com “A registrar” representam informações que ainda serão incluídas.

Os [padrões de organização](docs/padroes-de-organizacao.md) e o [registro das atualizações](docs/como-publicar-e-atualizar.md) fazem parte da documentação do portfólio.
